# 講師人力管理系統

補習班講師排課與人力管理工具，取代難以維護的 Excel 課表。

## 功能

- **講師課表**：每位講師一週（星期一～日）課表，**以 30 分鐘為一格**，可排任何特殊時段（例如 17:00–18:30）。
  - 在空白格子上拖曳選取時段即可排課，選擇分校與班級（例如 明道 國一數學）。
  - 可切換到「標記不可排」模式，標出講師「無法接」的時段。
  - 顯示每週總時數與各分校時數。
- **分校課表**：與講師課表共用同一份資料，互相連動。
  - 講師排好某分校的課，分校課表會自動出現該課程並註記講師（顏色代表講師）。
  - 也可以直接在分校課表排課、指定或更換講師；尚未指派講師的課程會以橘色虛線標示。
  - 下方列出每個班級的授課講師、上課時間與每週時數。
- **衝堂檢查**：同一講師同時段重複排課、排到講師不可排時段、同一班級時間重疊，都會即時提醒。
- **班級管理**：班級以「年級 + 科目 + 班別」組成，例如「國二英文 A班」；也可以設成「不分年級」的課程。
- **學期與年級進階**：
  - 按「＋ 新學期」會從現有學期複製課表（可選擇是否保留講師、是否複製不可排時段）。
  - 跨學年（例如 115下 → 116上）時，所有班級**自動升一個年級**（國一數學 → 國二數學）。
  - **畢業班（小六、國三、高三）以黃色高亮**，升上新學年後自動畢業；也可以勾選「延續」，讓畢業班直接升為下一學制的新班（國三數學 → 高一數學）。
  - 過去的學期仍保留當時的年級與課表，可以隨時切換查看。
- **列印**：課表可直接列印（A4 橫式）。
- **備份**：在「設定」匯出 / 匯入 JSON 備份檔。

## 使用方式

不需要安裝，直接用瀏覽器（Chrome / Edge / Safari）開啟 `index.html` 就能使用。

第一次開啟時會載入範例資料（依照原本 Excel 的沂彥、陳新課表），可到「設定 → 清空所有資料」後開始輸入自己的資料。

> 資料儲存在這台電腦的瀏覽器中（localStorage）。換電腦或清除瀏覽器資料前，請先到「設定」**匯出備份**。

也可以用本機伺服器開啟：

```bash
npm start   # http://localhost:8080
```

## 開發

- 純 HTML / CSS / JavaScript，不需要建置流程。
- `js/core.js`：年級、學期、衝堂、年級進階等核心邏輯（不依賴 DOM）
- `js/store.js`：資料儲存與範例資料
- `js/grid.js`：半小時週課表元件
- `js/app.js`：各畫面與對話框

執行測試：

```bash
npm test
```
