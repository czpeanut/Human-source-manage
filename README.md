# 講師人力管理系統

補習班講師排課與人力管理工具，取代難以維護的 Excel 課表。資料儲存在雲端（Firebase），多位管理員可同時使用，各分校可用專屬帳號密碼查看自己的課表。

## 功能

- **講師課表**：每位講師一週（星期一～日）課表，**以 30 分鐘為一格**，可排任何特殊時段（例如 17:00–18:30）。
  - 在空白格子上拖曳選取時段即可排課，選擇分校與班級（例如 明道 國一數學）。
  - 「標記不可排」模式可標出講師「無法接」的時段。
  - 顯示每週總時數與各分校時數。
- **分校課表**：與講師課表共用同一份資料、互相連動。講師排好某分校的課，分校課表會自動出現該課程並註記講師；也可以直接在分校課表排課、指定或更換講師。
- **衝堂檢查**：講師重複排課、排到講師不可排時段、同班時間重疊，都會即時提醒。
- **班級與年級進階**：跨學年建立新學期時，所有班級自動升一個年級（國一數學 → 國二數學）；**畢業班（小六、國三、高三）黃色高亮**，升上新學年後自動畢業，也可以選擇延續為下一學制的新班（國三數學 → 高一數學）。
- **雲端儲存**：資料存在 Firebase，任何電腦登入都能使用；多位管理員即時同步，同時修改時會提醒並載入最新資料。
- **分校展示頁**：管理員在「設定 → 分校展示帳號」為每個分校設定帳號密碼，分校用專屬連結登入後**只能看到自己分校的課表**（唯讀，自動更新，可列印）。
- **列印**、**JSON 備份匯出 / 匯入**。

## 頁面

| 頁面 | 使用者 | 說明 |
| --- | --- | --- |
| `index.html` | 管理員 | 排課、班級、講師、分校管理 |
| `branch.html` | 分校 | 以分校帳號密碼登入，唯讀查看自家課表 |

## 雲端設定（第一次，約 15 分鐘）

使用 Google 的 Firebase 免費方案（Spark），一般補習班的用量不需付費。

1. **建立專案**：到 [Firebase 主控台](https://console.firebase.google.com/) →「新增專案」，名稱自訂（Google Analytics 可以關閉）。
2. **開啟登入功能**：左側「建構 → Authentication」→「開始使用」→「登入方式」→ 啟用「**電子郵件/密碼**」。
3. **建立管理員帳號**：Authentication →「使用者」→「新增使用者」，輸入管理員的 Email 與密碼。（有多位管理員就建立多個）
4. **建立資料庫**：「建構 → Firestore Database」→「建立資料庫」→ 位置選 `asia-east1（台灣）`→ 選「**正式版模式**」。
5. **設定安全規則**：Firestore →「規則」分頁，把本專案 `firestore.rules` 的內容整個貼上，並把
   ```
   'admin@example.com'
   ```
   換成第 3 步的管理員 Email（多位用逗號分隔，例如 `'a@gmail.com', 'b@gmail.com'`），按「發布」。
   > 只有列在這裡的 Email 能進入管理頁；之後新增管理員也要改這裡。
6. **取得網頁設定**：「專案設定（齒輪）→ 一般 → 你的應用程式」→ 點 `</>`（網頁）新增應用程式 → 複製畫面上的 `firebaseConfig`，貼到 `js/config.js`：
   ```js
   window.HSM_CONFIG = {
     firebase: {
       apiKey: 'AIza...',
       authDomain: 'your-project.firebaseapp.com',
       projectId: 'your-project',
       appId: '1:...:web:...',
     },
   };
   ```
   > 這些值本來就會放在網頁中，不是密碼；資料安全由第 5 步的規則保護。
7. **放上網路**（二選一）：
   - **Firebase Hosting**（推薦）：電腦安裝 [Node.js](https://nodejs.org/) 後，在專案資料夾執行
     ```bash
     npx firebase-tools login
     npx firebase-tools use --add      # 選擇你的專案
     npm run deploy                    # 同時發布網站與安全規則
     ```
     完成後網址為 `https://你的專案.web.app`。
   - **GitHub Pages**：GitHub 儲存庫「Settings → Pages」→ Source 選 `main` 分支、`/ (root)`。完成後到 Firebase「Authentication → 設定 → 已授權網域」加入 `你的帳號.github.io`。

第一次用管理員登入時，如果這台電腦有之前本機模式的資料，系統會詢問是否上傳到雲端。

## 給分校帳號

1. 管理頁「設定 → 分校展示帳號」（或分校課表上方「分校展示帳號」），按「設定」。
2. 輸入帳號（小寫英文，例如 `mingdao`）與密碼（可按「重新產生」），儲存。
3. 按「複製連結」，把連結與密碼交給分校。分校打開連結、輸入密碼即可看到自己的課表。
4. 「預覽」可以看分校登入後的畫面；「修改」可換密碼（舊密碼立即失效）；「停用帳號」後分校無法再登入。

安全性：分校帳號只能讀取自己分校的展示資料（班級、上課時間、授課講師姓名），無法讀取其他分校、講師備註、不可排時段或任何可修改的資料——這由 Firestore 安全規則在伺服器端強制執行。分校密碼會存在雲端，只有管理員看得到，方便轉交分校。

## 本機模式（試用）

`js/config.js` 的 `firebase` 為 `null` 時是本機模式：直接用瀏覽器開啟 `index.html` 即可試用，資料只存在這台電腦的瀏覽器，第一次會載入範例資料（依原本 Excel 的沂彥、陳新課表）。

## 開發

純 HTML / CSS / JavaScript，不需要建置流程。

| 檔案 | 說明 |
| --- | --- |
| `js/core.js` | 年級、學期、衝堂、年級進階、分校展示資料（不依賴 DOM，有單元測試） |
| `js/store.js` | 資料狀態與範例資料 |
| `js/cloud.js` | Firebase / 本機模式存取層 |
| `js/sync.js` | 雲端同步、衝突偵測、發布分校展示資料 |
| `js/grid.js` | 半小時週課表元件 |
| `js/app.js` | 管理頁 |
| `js/branch.js` | 分校展示頁 |
| `firestore.rules` | Firestore 安全規則 |

```bash
npm test            # 單元測試
npm run emulators   # 啟動 Firebase 模擬器（需要 Java）
npm start           # http://localhost:8080
```

使用模擬器時開啟 `http://localhost:8080/index.html?emulator=demo-hsm`，並在模擬器中建立 `admin@example.com` 帳號。
